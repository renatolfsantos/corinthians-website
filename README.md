# Corinthians Fan Website

Um projeto web interativo inspirado na história, identidade e cultura do Sport Club Corinthians Paulista. Desenvolvido com foco em uma experiência visual moderna, combinando animações, efeitos gráficos e apresentação dinâmica de conteúdo.

## Sobre o projeto

O Corinthians Experience é um projeto desenvolvido para explorar diferentes tecnologias e técnicas de desenvolvimento web, com foco na criação de uma experiência visual interativa e imersiva.

O site apresenta conteúdos relacionados ao Corinthians por meio de uma interface dinâmica, incluindo animações baseadas em scroll, uma timeline interativa sobre momentos marcantes da história do clube, apresentação do elenco e informações sobre partidas.

A proposta do projeto é unir desenvolvimento frontend, animação, efeitos visuais e integração com uma API, priorizando responsividade, organização e performance.

### Outras tecnologias

* Git
* GitHub

## Funcionalidades

* Página inicial com elementos visuais interativos
* Background com vídeo e shader personalizado
* Animações utilizando GSAP
* Animações baseadas em scroll com ScrollTrigger
* Timeline interativa apresentando momentos da história do Corinthians
* Transições visuais e efeitos aplicados às imagens durante a navegação
* Seção com informações sobre o elenco
* Exibição de informações sobre próximas partidas
* Integração entre frontend e backend באמצעות API REST
* Layout responsivo
* Carregamento otimizado de imagens e outros recursos visuais
